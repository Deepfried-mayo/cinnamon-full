# cinnamon-full
## Info:
  - This theme is a fork of Mint-Y-Dark-Aqua by the Linux Mint team
  - This theme aims to unify "cinnamon" theme from Cinnamon DE, which is only for the desktop, with GTK apps

## How to use this theme:
  1. Move or copy the "cinnamon-full" folder into `/usr/share/themes`, `~/.themes` or `~/.local/share/themes`
  2. Apply the theme in System Settings
